# Multilaminar simulation
Simulation and analysis code accompanying the paper Szul et al. (2025) "Beyond deep versus superficial: true laminar inference with MEG"

Requirements
============
* Python v3.7
* [laMEG v0.0.7](https://github.com/danclab/laMEG)
* pandas v1.3.5
* PIL v9.5.0
* [VBA toolbox](https://mbb-team.github.io/VBA-toolbox/) for Bayesian model comparison
